# Security and personal information

Report a security or privacy issue through the repository's [Security advisories](https://github.com/dabeeruhlaq12-cell/Jawabdeh/security/advisories) page if private reporting is available. If the report button is unavailable, open an issue requesting a private contact method and wait for a reply before sharing details.

Keep personal complaint details, private contact information, and vulnerabilities out of public issues and pull requests. Use synthetic examples where possible. For routine corrections to public office contact details, follow [the contribution guide](CONTRIBUTING.md).
